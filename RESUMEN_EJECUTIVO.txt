OBJETIVO
────────

Desarrollar una solución mediante Programación Dinámica para el problema
"Torta de Cumpleaños", donde dos jugadores (Profesor y Hermana) se alternan
eligiendo n porciones consecutivas de una torta dividida en 2n partes,
buscando maximizar la satisfacción garantizada del Profesor.

RESUMEN TÉCNICO
────────────────

ESQUEMA SRTBOT IMPLEMENTADO:

S (Subproblema):
  f(i, j, turno) = máxima satisfacción del Profesor cuando quedan porciones
                   [i, j] y es el turno del jugador indicado (0=Profesor, 1=Hermana)

R (Relación):
  • Caso base (tamaño < n):     f = 0
  • Caso base (tamaño == n):    f = suma(i:j+1) si turno==0, else 0
  • Recursivo (tamaño > n):
    - Turno 0: max { suma + f(..., turno=1) }
    - Turno 1: min { f(..., turno=0) }

T (Tabla):
  • Versión 1: Diccionario (hash table) - Top-down recursivo
  • Versión 2: Arreglo 3D - Bottom-up iterativo

B (Borde):
  • Menos de n porciones → retorna 0
  • Exactamente n porciones → retorna suma (Profesor) o 0 (Hermana)

O (Orden):
  • Versión hash: Memoización top-down (bajo demanda)
  • Versión arreglo: Bottom-up por tamaño creciente

T (Tipo):
  Entero o flotante representando máxima satisfacción garantizada
