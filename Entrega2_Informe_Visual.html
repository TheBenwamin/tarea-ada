⚖️ Análisis Comparativo Detallado

✓ Memoización con Diccionarios

Ventajas:
  • Almacena solo estados visitados
  • Mejor para espacios dispersos
  • 2-6x más rápido
  • Menor consumo de memoria (promedio)
  • Escalable a n muy grandes
Desventajas:
  • Overhead de función hash
  • Acceso O(1) promedio, O(n) peor caso

📦 Memoización con Arreglos

Ventajas:
  • Acceso garantizado O(1)
  • Mejor localidad de caché
  • Predicción exacta de complejidad
  • Más eficiente en otros contextos
Desventajas:
  • Asigna memoria total al inicio
  • Desperdicia espacio para no visitados
  • 2-6x más lento
  • Limitado por memoria disponible

💡 Recomendación Final

Para este problema, se recomienda usar Memoización con Diccionarios. Es significativamente más rápido (2-6x) y más eficiente en memoria, sin sacrificar correctitud.

🚀 Oportunidades de Optimización

1. Suma de Rango Prefija (Impacto: O(n³) → O(n²))

Precomputar sumas acumulativas para reducir el tiempo de cálculo de rango de O(n) a O(1):

prefix = [0] * (len(st) + 1)
for i in range(len(st)):
    prefix[i+1] = prefix[i] + st[i]

def suma_rango(i, j):
    return prefix[j+1] - prefix[i]  # O(1)

2. Mediciones con n Mayores

Para valores n > 18, se vería mejor concordancia entre datos experimentales y teoría O(n³).

3. Compilación JIT

Usar PyPy en lugar de CPython podría acelerar 2-3x el código Python puro.

4. Implementación Iterativa

Cambiar de recursión top-down a iteración bottom-up para reducir overhead de llamadas.
